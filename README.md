# Snake i Python

Bygg det klassiska spelet Snake med `pygame`.

## Kom igång

```bash
pip install pygame
python snake.py
```

## Uppgifter

1. Låt ormen växa när den äter ett äpple.
2. Avsluta spelet när ormen krockar med sig själv eller kanten.
3. Visa poäng och highscore.
4. Extra: lägg till svårighetsnivåer.
